# ADR 0001：以一般檔案儲存二進位資產

- 狀態：已被 ADR 0003 取代
- 日期：2026-08-18

## 背景

MVP 部署於 QNAP，會保存無法由外部資料來源重新取得的相片，以及規則書等附件。即使應用程式或資料庫損壞，擁有者仍須能透過 NAS 的一般檔案工具備份與救回這些內容。

可選方案包括：

1. 把二進位內容存成資料庫欄位。
2. 使用 S3 相容物件儲存。
3. 存成 NAS 檔案系統中的一般檔案，資料庫只記錄關聯與中繼資料。

## 決策

MVP 採用第三案。

- 自訂封面、相簿圖片與遊戲附件存放在一個可設定、可掛載及可備份的資料根目錄下。
- 檔案維持為可由一般工具讀取的原始格式，不封裝進資料庫或專屬容器。
- 資料庫保存相對路徑、所屬遊戲、顯示名稱、說明、媒體類型與時間等中繼資料。
- 資料庫與檔案資料夾是一組完整備份；部署與還原文件必須同時涵蓋兩者。
- MVP 不引入 S3 相容物件儲存。

## 後果

優點：

- 應用程式無法啟動時，檔案仍可由 QNAP 直接備份及救回。
- 不需要額外維運物件儲存服務。
- 大型圖片與 PDF 不會膨脹資料庫。

代價：

- 資料庫寫入與檔案寫入無法天然共用同一個交易。
- 必須處理上傳中斷、孤兒檔案、遺失檔案與刪除失敗，且不可靜默忽略。
- 只備份資料庫或只備份檔案目錄，都無法完整還原系統。

## 後續決策

MVP 正式部署目標已改為 Vercel，因此無法依賴 QNAP 掛載目錄作為線上儲存。本 ADR 由 [ADR 0003](0003-deploy-on-vercel-with-managed-storage.md) 取代，儲存供應商再由 [ADR 0004](0004-use-supabase-postgres-and-storage.md) 定案；「檔案可用一般工具救回」的需求將由 MVP 後的第一優先項目，以定期下載 Supabase Storage 物件至 QNAP 的可攜備份實現。
