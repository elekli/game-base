# ADR 0002：私人使用時永久保存來源封面

- 狀態：已接受
- 日期：2026-08-18

## 背景

MVP 需要在 BoardGameGeek 或 IGDB 無法使用及網路中斷時，仍能顯示既有遊戲封面。API 調查顯示，IGDB 圖片永久鏡像與 BoardGameGeek 圖片下載／縮圖的條款範圍仍有待書面確認。

本系統的既定用途是單一擁有者、非商業且受存取控制保護，不是公開圖片服務。正式環境改由 Vercel 執行，QNAP 作為備份目的地。

## 決策

- 來源封面與使用者自訂封面都永久保存於私有 Supabase Storage bucket，不採不同保存期限。QNAP 異地備份列為 MVP 後的第一優先項目。
- 系統保留資料來源名稱、來源識別碼及原始頁面連結，不把來源圖片宣稱為使用者自有內容。
- 本決策視為擁有者在私人使用範圍內明確接受尚未完全釐清的條款風險，不代表判定來源條款必然允許所有重用方式。
- 若系統改為公開服務、商業用途、多人服務或對外散布，必須先重新審查 BoardGameGeek、IGDB 與 Twitch 的現行條款，再決定是否延續本做法。

## 後果

優點：

- 外部中繼資料來源失效時，既有條目與封面仍可透過線上應用程式瀏覽；本決策不代表 MVP 支援離線模式。
- MVP 後的備份將包含完整可視內容，不依賴外部圖片網址持續有效。
- 來源封面與自訂封面將採相同的備份及還原流程。

代價：

- 接受目前文件間尚未完全排除的授權風險。
- 用途一旦擴大，就必須把條款複核視為發布前的硬性關卡。
